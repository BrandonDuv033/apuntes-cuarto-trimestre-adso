## 💬 Everyday Useful Phrases

| Frase (EN) | Uso / Significado (ES) |
|---|---|
| How's it goin'? | ¿Cómo estás? ¿Qué has estado haciendo? |
| What have you been up to? | Iniciar una conversación: ¿qué hay de nuevo? ¿qué has hecho desde la última vez? |
| How have you been? | ¿Cómo has estado? |
| I've been... | Forma de responder a las preguntas anteriores |
| How about...? | Preguntar qué ha pasado con algo/alguien, o proponer un plan |
| Sorry, I can't | Forma corta de negarse a hacer algo |
| Sure, sounds good! | Aceptar una invitación o un plan |
| Do you want to...? | Proponer algo, hacer una invitación |
| What do you call this? | ¿Cómo le llamas a esto? |
| How do I get to (location)? | ¿Cómo puedo llegar a este lugar? |
| Have a nice evening! | Despedida al irse temprano de un evento |
| Have a good one! | Despedida informal / nativa |
| Can I have [item], please? | Pedir algo en cualquier contexto |
| [#] of the [noun], please | Especificar cantidad de algo que se pide |
| How do I [verb phrase]? | Preguntar cómo hacer algo (ej. en el banco) |
| How late are you open? | Hasta qué hora está abierto |
| Do you have any plans for [time]? | Preguntar disponibilidad antes de invitar |
| My [body part] hurts | Indicar qué parte del cuerpo duele |
| How much is this? | Preguntar el precio de algo |
| What did you say? / What was that? | Pedir que repitan o confirmen algo |

## ⏰ Prepositions of Time

Se colocan antes de una referencia temporal.

| Ejemplo incorrecto | Ejemplo correcto |
|---|---|
| La clase es a 10 ❌ | La clase es **a las** 10 ✅ |
