# Componentes

Un componente de React es una función que devuelve una interfaz de usuario.

## Ejemplo básico

```jsx
function App() {
  return (
    <>
      Hola mundo
    </>
  );
}

export default App;
```

## 📌 `export default`

Permite exportar el componente para poder utilizarlo/importarlo desde otro archivo.
