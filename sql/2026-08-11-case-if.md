## 🔹 CASE

`CASE` permite establecer condiciones dentro de una consulta y devolver un resultado según cuál se cumpla.

```sql
CASE
    WHEN condicion THEN resultado
    WHEN condicion THEN resultado
    ELSE resultado
END
```

| Palabra clave | Función |
|---|---|
| `WHEN` | Condición a evaluar |
| `THEN` | Resultado si la condición se cumple |
| `ELSE` | Resultado si ninguna condición anterior se cumple |
| `END` | Finaliza el `CASE` |
| `AS` | Asigna nombre a la columna resultante |

```sql
SELECT desc_producto, precio,
CASE
    WHEN precio < 50 THEN 'Económico'
    WHEN precio <= 150 THEN 'Medio'
    ELSE 'Costoso'
END AS observacion
FROM productos;
```

## 🔹 CASE con INNER JOIN

```sql
SELECT c.nombre_cliente, co.tipo_comprobante,
CASE
    WHEN co.tipo_comprobante = 'F' THEN 'Factura'
    WHEN co.tipo_comprobante = 'B' THEN 'Bono'
    ELSE 'Otros'
END AS tipos
FROM cliente c
INNER JOIN comprobante co
    ON c.id_cliente = co.cod_cli;
```

## 🔹 CASE con fechas

```sql
SELECT cod_comprobante, fecha,
CASE
    WHEN MONTH(fecha) <= 6 THEN 'Primer Semestre'
    ELSE 'Segundo Semestre'
END AS Semestre
FROM comprobante;
```

`MONTH(fecha)` obtiene el número del mes: **1–6** → Primer semestre, **7–12** → Segundo semestre.

> ⚠️ En el apunte original decía "Segundo Trimestre", pero para dividir el año en 1–6 y 7–12 lo correcto es **Segundo Semestre**.

## 🔹 CASE con funciones de agregado

```sql
SELECT p.desc_producto,
       SUM(dt.cantidad_vendida) AS cantidad_total,
CASE
    WHEN SUM(dt.cantidad_vendida) > 100 THEN 'Venta alta'
    WHEN SUM(dt.cantidad_vendida) > 50 THEN 'Venta media'
    ELSE 'Venta baja'
END AS clasificacion_nivel
FROM productos p
INNER JOIN detalle_comprobante dt
    ON p.id_producto = dt.id_producto
GROUP BY p.id_producto;
```

Primero se agrupan las ventas de cada producto y después se clasifican.

## 🔹 IF()

```sql
IF(condición, resultado_si_verdadero, resultado_si_falso)
```

```sql
SELECT desc_producto, precio,
IF(precio < 50, 'Económico',
   IF(precio <= 100, 'Medio', 'Costoso'))
AS precios
FROM productos;
```

## 🔹 CASE vs IF

| CASE | IF |
|---|---|
| Permite varias condiciones | Ideal para condiciones sencillas |
| Usa `WHEN` / `THEN` | `IF(condición, verdadero, falso)` |
| Más organizado para muchas condiciones | Más compacto |
